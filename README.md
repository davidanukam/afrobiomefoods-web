# AfroBiome Foods Website

Nonprofit marketing site for AfroBiome Foods Incorporated — cultivating culturally relevant African vegetables for Black and African diaspora communities in Southwestern Ontario.

## Design

See [DESIGN-BRIEF.md](./DESIGN-BRIEF.md) for colors, typography, motion, and section wireframes.

**Direction:** Savor atmosphere × Farm Minerals hero × sweetgreen produce system × Mammoth/Zipline impact type.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Fraunces + Figtree

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Path | Content |
|---|---|
| `/` | Home — hero, problem/solution, pillars, crops teaser, impact, CTA |
| `/story` | Mission, vision, guiding pillars |
| `/farms` | Clarke Road, Pleasant Valley, Hamilton Road |
| `/crops` | Leafy greens & vegetables |
| `/impact` | Metrics, food box program, SROI |
| `/get-involved` | Volunteer, donate, partner |

Donation and volunteer CTAs currently use `mailto:` placeholders until a payment/volunteer provider is connected.
